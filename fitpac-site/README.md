# FitPac Website

A complete responsive HTML/CSS/JS landing page inspired by the information architecture and visual language of modern flexible-packaging B2B sites.

## Files

- `index.html` — page structure/content
- `styles.css` — responsive visual system
- `script.js` — navigation, tabs, animations, counters, form demo
- `assets/fitpac-logo.png` — cropped version of the supplied FitPac logo

## Deploy

Upload the entire folder to any static host, or simply open `index.html` locally.

Works with:
- Netlify
- Vercel static hosting
- GitHub Pages
- Cloudflare Pages
- Any standard web server

## Before production

1. Replace `hello@fitpac.com` with the real sales email.
2. Connect the quote form to Formspree, your CRM, or your own backend.
3. Replace the CSS mock product visuals with real product photography if desired.
4. Add your real company address, phone, certifications and production figures.
5. If using Google Fonts is not desired, self-host the fonts and remove the Google Fonts import.
